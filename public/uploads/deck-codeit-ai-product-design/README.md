# AI를 활용한 프로덕트 디자인 — 코드잇 사전과제 덱

10분 강의용 **19장**. 디자인 시스템은 **Nocturne**, 구조는 `deck-problem-definition`(문제정의 교안)과 동일.

## 관통 메시지

> AI는 검증을 대신하지 않는다. 검증까지 가는 길을 짧게 만들 뿐이다.

이론 골격은 **검증 루프** — [0] 무엇을 검증할지 좁히기(AI) → [1] 검증할 물건 만들기(AI·바이브 코딩) → [2] 실제 사람에게 보여주기(사람만) → [3] 고쳐서 다시 0번.

## 파일

| 파일 | 용도 |
|---|---|
| `index.html` | **편집·발표용.** 교안과 같은 `deck-stage` 런타임. 발표자 노트·슬라이드 네비게이션 지원 |
| `print.html` | **PDF 출력용.** 런타임 없이 정적 렌더링. `@page 1920×1080` |
| `deck.css` | 교안 원본 + 이 덱 전용 컴포넌트 (`.flow-step.on/.off` `.versus` `.qcompare` `.quote-human` `.demo-thumb` `.dcard .evidence` `.split` `.steps.boxed`) |
| `assets/demo-thumb.png` | 슬라이드 16 데모 썸네일 (1388×891, 렌더 810×520) |
| `_ds/nocturne-.../styles.css` | Nocturne 토큰 — 원본 그대로, 무수정 |

## 타임라인 (대본 2,788자 · 300자/분 + 데모 25초 + 멈춤 6초 ≈ 9:48)

| 구간 | 슬라이드 | 시간 |
|---|---|---|
| 오프닝 | 01–03 | 0:00–0:37 |
| ① 이론 | 04–08 | 0:37–3:12 |
| ② 사례 | 09–17 | 3:12–7:50 |
| ③ 실습 안내 | 18 | 7:50–9:18 |
| 클로징 | 19 | 9:18–9:42 |

**체크포인트는 3:12 하나.** 여기서 늦으면 실습이 잘린다.

## 촬영 시

- **멈춤 2곳** — 13번("왜 하필 권한 없는 사람한테?"), 17번("아직 검증되지 않았습니다") 뒤 각 2~3초
- **17번에서 목소리를 낮추지 말 것.** 한계를 말하는 대목에서 위축되면 변명처럼 들린다. 담담하게 사실로
- **16번 데모 시연은 20~30초.** 썸네일 클릭 → 계정 전환 한 번, 시간 진행 한 번. 그 이상 들어가면 시간이 무너진다
- 사례 파트(09–17)는 대본을 읽지 말고 키워드만 보고 말할 것. 이 파트만 톤이 달라야 한다
- 실습(18번)은 **돌아가서 할 과제**다. 지금 같이 하는 게 아니라는 걸 먼저 말한다

발표자 노트는 각 `<section>`의 `data-speaker-notes` 속성에 있다.

## PDF 출력

`print.html`을 브라우저로 열고 → 인쇄 → **PDF로 저장** → 배경 그래픽 켜기. 여백 없이 16:9 19장.

> `index.html`은 unpkg에서 React를 받아오므로 **인터넷 연결 필요**.
> `print.html`은 Google Fonts만 외부에서 받는다.
